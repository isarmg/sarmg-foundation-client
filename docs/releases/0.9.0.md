# 0.9.0

This release makes the authenticated, read-only local runtime-status protocol a Client Foundation capability. Desktop products now consume one implementation for bounded snapshots, binding-generation checks, Unix peer credentials, and protected Windows named pipes instead of maintaining product copies.

The secure HTTP documentation also records the implemented pooled-client semantics precisely: eligible clients are reused within the bounded address lease, while DNS lease expiry and transport connection lifetime remain separate concerns.

The cross-platform transport fixture now treats temporary nonblocking and timeout reads as retryable until its fixed deadline, removing a macOS scheduling race without weakening any production timeout or response budget.
