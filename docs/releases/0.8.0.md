# 0.8.0

`PublicHttps` now rejects loopback, private, link-local, carrier-grade NAT, documentation, benchmark, multicast and reserved address ranges after DNS resolution, closing the public/private network-policy gap. Validated address sets reuse one short-lived pinned HTTP client when DNS answers are unchanged, restoring connection pooling without weakening rebinding protection.

TLS trust is explicit through `TrustMode`: system roots, system plus custom roots, or custom roots only. This replaces ambiguous custom-root merging. Native Windows and macOS CI now compiles and tests the secure HTTP implementation.

The Client policy checker scans every Cargo manifest independently of advisory source roots and rejects symlinked source directories. Windows entry names reject NTFS alternate data streams and reserved Win32 aliases. Secret-envelope object bindings are capped at 4096 bytes, and delivery recovery polling rejects intervals below 100 ms while using fair scheduling.
