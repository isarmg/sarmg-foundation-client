# Sarmg Foundation Client 0.6.0

## 发布后验收：预发布 / Windows 阻断

2026-09-05 的 Host Windows 原生 CI 确认：`PrivateDirectory::create` 在目录上使用普通 `File::open` 返回 AccessDenied，Spool 无法打开。非 Unix 路径的目录同步及只读文件同步也尚未获得 Windows 持久化验收。该版本不能作为可用的 Windows Client 基础库发布；发行页标记为预发布，源码标签和已上传制品保持不变。

必须实现并验收原生句柄、reparse-point/ACL 和持久化边界后，以新版本修复；不能忽略同步错误或跳过失败测试。Linux 验收结果不受此声明替代，也不构成 Windows、macOS 或移动端完整运行证明。

失败证据：[Host Windows CI](https://github.com/isarmg/host-monitoring/actions/runs/33977671184/job/101337134982)。

首次独立发布的客户端基础库。只规定桌面 Client、Android/iOS、移动 FFI 和客户端本地管理 Web；Server 管理 Web 不属于本仓库。

- 独立的 7 个 Rust crate、2 个客户端 Profile，不依赖 Server Foundation，也不保留旧名称兼容入口。
- 有界 Spool、投递与退避、凭据快照、身份绑定；身份不匹配记录保留原始字节并隔离，不发送、不自动删除。
- 有界出站 HTTP、请求拥有的 DNS 任务与关闭、地址和 TLS 校验。
- ABI 2 的移动 FFI、代际句柄、结果所有权及 panic 边界。

发布物是供 Cargo 按完整 Git revision 和精确版本消费的源码基础库，不是预编译的 Android/iOS/Windows/macOS SDK。CI 验证 Linux 上的策略、全特性 Rust 测试、严格 Clippy，以及优化构建下的 HTTP/DNS 边界。原生平台验收仍须在各平台执行。

本版本是当前改造工作的阶段发布，不表示《更新手册》全部完成；不包含旧版本数据升级或兼容层。
