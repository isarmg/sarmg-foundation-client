# sarmg-foundation-client v0.9.12

- 修正 `desktop-client` Profile 的上游边界：HTTPS 投递 Adapter 是唯一通用必选能力；Spool、Foundation 私有状态、Doctor、本机状态和完整服务生命周期按消费者实际采用情况声明。
- 新增产品中立的 `protected-terminal-input` 能力，准确描述 Host、Sunshine、Sentinel 共用的原生有界终端输入。
- Sentinel 等实时流 Client 不再需要虚假声明批量 Spool；Spool 限额和实现所有权检查仍严格应用于明确声明 `bounded-spool` 的消费者。
