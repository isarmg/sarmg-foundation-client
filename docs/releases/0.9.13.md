# sarmg-foundation-client v0.9.13

- 将产品中立的 `sarmg-secure-xml` 从 Foundation Server 迁入 Client Foundation，消除 Client 对 Server 上游的反向依赖。
- 新增可选 `bounded-xml` 能力；有界解析统一拒绝 DTD/ENTITY，并限制输入、深度、节点、文本及解析时间。
- ONVIF SOAP、命名空间、设备字段和具体预算仍由 Sentinel Client 负责。
- Client 消费者边界检查允许该 Client Foundation 包，同时继续拒绝所有 Foundation Server 源依赖。
