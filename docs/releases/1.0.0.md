# xcsc 1.0.0

此版本将当前实现整理为 1.0.0 发布基线，正式标签为 `v1.0.0`，`main` 从一个初始提交开始。

项目、软件包、命令、服务、安装产物及移动端标识按统一四字母命名表更新；最后一位 `s` 表示服务端，`c` 表示客户端。当前项目名及唯一 Rust package 为 `xcsc`。Client 通过 `xcsc::<module>` 获取公共能力。

本轮将原有 Client Rust 实现物理合并为单包，并纳入独立 Client 日志及受 feature/平台约束的离线维护机制。Windows、macOS、Android/iOS 的模块与原生安全约束保留；离线工具通过同包的显式 feature 获取维护能力。C ABI revision 1、导出函数、结构和预算不变。详细模块、features 与检查命令见[单体说明](../monolithic-client.md)。

产品依赖固定到新的 1.0.0 基础库和提交。协议版本、数据库结构版本及第三方工具版本独立管理，不随软件发布版本重置。

升级前导出配置和业务数据，停止并卸载旧名称的服务，再按当前部署指南安装和重新配对。旧数据目录、系统服务及移动应用标识不会自动迁移。基础库项目通过依赖方式接入，无需单独安装后台服务。

参见[项目 README](../../README.md)与[统一命名表](../naming.md)。

## 内部版本从初始值开始

本次重建的软件发行号为 `1.0.0`。项目自定义的配置、持久状态、数据库 schema、API、通信协议、ABI 和发行清单均以 `v1` 或数值 `1` 作为初始标识；使用语义版本作为身份的配置采用 `1.0.0`。第三方依赖、外部软件 API 和字体上游版本遵循其实际版本要求。

服务端与客户端须成对安装本次 1.0.0 发行物。旧版配置或数据库不直接覆盖新目录；先导出数据并保留备份，再按平台部署文档重新安装和配对。
