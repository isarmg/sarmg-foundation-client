# Foundation Client 0.9.5

Interactive CLI input now uses the controlling terminal directly. Unix clients
use a bounded `termios`/`poll` loop and Windows clients use the native Console
API; secret input no longer starts `stty` or PowerShell subprocesses.

The new `prompt_text` and `prompt_secret` APIs require an explicit byte limit
and absolute deadline. Secret prompts explain that input is hidden, erase their
buffers on drop, handle cancellation and timeout, and restore the terminal mode
on every tested exit path.
