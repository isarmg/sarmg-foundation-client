# xcsc 1.0.1

本版修复公共终端配置编辑器对 `VISUAL` / `EDITOR` 参数的支持，例如 `code --wait` 和 `vim -f`。已有可执行路径继续按字面值优先启动，包括含空格路径；Windows 保留原生可执行文件查找。Unix 使用 POSIX 引号解析，Windows 使用原生命令行解析；不执行 shell 展开，临时 JSON 路径作为独立参数追加。GUI 编辑器需等待编辑完成后退出。

`VISUAL` 的优先级、交互终端要求、编辑器非零退出处理、编辑后 JSON 读取与产品侧验证/修订检查保持不变。配置格式、协议、ABI 和持久状态版本不变。

自 `v1.0.0` 起还包含已合入的接入、配置、使用、排障及各平台构建文档，以及普通文档改动的 CI 范围优化；源码、发布输入和安全审查文件改动仍运行完整验证。

产品接入应将 xcsc 包版本固定为 `=1.0.1`，同时固定本版标签对应的完整提交 revision 并更新 `Cargo.lock`，随后执行消费检查和产品测试。此库不单独部署。详见[接入文档](../getting-started.md)、[编辑器用法](../usage.md#终端配置编辑器)和[测试要求](../development.md)。

编辑器回归包含 Unix 字节/引号及 Windows UTF-16、反斜杠、路径和原生可执行文件扩展名。跨平台编译不代表原生行为验证；Windows 和 macOS 的执行结果以对应原生 CI 为准。
