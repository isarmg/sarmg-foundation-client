# 0.7.1

Apple filesystem validation now uses `O_NOFOLLOW_ANY` to reject symlinks throughout the path in one kernel lookup. It no longer opens every directory above the application container. This supports sandboxed mobile database and staging paths without permitting symlink aliases.

The mobile ABI can return reviewed, static product error messages while preserving revision 2, status codes, owned buffers and error redaction. Products can distinguish database opening stages without exposing filesystem paths or credentials.

Validation includes a real macOS sandbox that denies metadata and directory reads on an ancestor while allowing the application container, plus existing Windows/Linux storage and FFI tests. A simulator or macOS sandbox does not substitute for final iPhone acceptance.
