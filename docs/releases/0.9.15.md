# sarmg-foundation-client v0.9.15

- 命令行终端输入采用有界等待，安全处理高编号文件描述符；超时与取消返回稳定的客户端错误。
- 读取秘密 JSON 时，失败路径也会清理已进入内存的敏感缓冲区。
- Foundation 命令行层仅解析通用配置和状态参数，产品专属文件参数由产品适配层校验。
- 依赖边界检查覆盖 workspace、目标平台依赖、重命名依赖、patch/replace 与本地路径，并拒绝越界声明。
- 文档与测试示例描述当前通用客户端契约，不含产品专属实现。

本版本保持各 crate 的统一精确版本。消费者应同时固定 `=0.9.15` 和本次发布对应的完整 Git revision。
