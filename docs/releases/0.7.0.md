# Sarmg Foundation Client 0.7.0

客户端基础库统一名称为 `sarmg-foundation-client`，独立维护 Git/GitHub、构建、测试和源码发行。

- 六个客户端 Rust 包统一为 `sarmg-client-*`，通用移动 FFI 仍为 `sarmg-mobile-ffi`。
- 客户端类型、策略工具、Profile 和清单统一为 Client 命名，产品使用 `sarmg-client.toml`。
- 仅规定桌面客户端、Android/iOS、移动 FFI 及客户端自身的管理 Web；Server 管理 Web 不属于本仓。
- 不提供旧包名、旧配置键、旧 Profile 或旧状态格式的兼容入口。HTTP 标准 `User-Agent` 不变。
- 沿用当前原生 Windows 目录句柄/Spool 修复；Linux 与 Windows 分别运行原生测试。

发布物为绑定完整源码提交的源代码库，不是各平台预编译 SDK。移动平台和产品自身仍须独立验收。
