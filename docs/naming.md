# 项目命名

当前项目统一使用以下名称。最后一位 `c` 表示客户端，`s` 表示服务端；共享库通过编译依赖接入。

| 项目 | 名称 | 中间两字母 | 助记含义 |
|---|---|---|---|
| 网页文件管理器 | `xczs` | `cz` · Content Zone | 文件内容空间 |
| 系统监控 | `xsos` / `xsoc` | `so` · System Observation | 系统状态观测 |
| Sunshine 控制与管理 | `xscs` / `xscc` | `sc` · Sunshine Control | Sunshine 控制与管理 |
| 媒体备份 | `xszs` / `xszc` | `sz` · Storage Zone | 备份存储空间 |
| 客户端公共基础库 | `xcsc` | `cs` · Common Support | 公共基础支撑 |
| 摄像头监控 | `xcos` / `xcoc` | `co` · Camera Observation | 摄像头观测 |
| 软件升级工具 | `xssc` | `ss` · Software Switch | 软件版本切换 |
| 个人博客 | `xocs` | `oc` · Online Chronicle | 在线个人记录 |
