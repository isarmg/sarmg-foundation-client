# 项目命名

仓库、CLI 与部署产物均使用以下小写四字母名称。后缀 `c` 为 client，后缀 `s` 为 server。

| 项目 | 四字母名称 | 中间两字母 | 助记含义 |
|---|---|---|---|
| **dufs：网页文件管理器** | **`xczs`** | `cz` · Content Zone | 文件内容空间 |
| **host-monitoring：主机监控** | **`xsos` / `xsoc`** | `so` · System Observation | 系统状态观测 |
| **sunshine-manager：Sunshine 第三方管理** | **`xscs` / `xscc`** | `sc` · Sunshine Control | Sunshine 控制与管理 |
| **media-backup：媒体备份** | **`xszs` / `xszc`** | `sz` · Storage Zone | 备份存储空间 |
| **sarmg-foundation：公共上游依赖包** | **`xcss` / `xcsc`** | `cs` · Common Support | 公共基础支撑 |
| **sentinel：摄像头监控** | **`xcos` / `xcoc`** | `co` · Camera Observation | 摄像头观测 |
| **sarmg-upgrade：升级工具** | **`xssc`** | `ss` · Software Switch | 软件版本切换 |
| **POETIZE：个人博客** | **`xocs`** | `oc` · Online Chronicle | 在线个人记录 |
